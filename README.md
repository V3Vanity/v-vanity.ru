# 🚀 Vanity Corp — Сайт-портфолио веб-разработчика

> Современный, адаптивный сайт-портфолио с анимациями, слайдером и формой обратной связи.

---

## ✨ Особенности

| Фича | Описание |
|------|----------|
| 🎨 **Современный дизайн** | Тёмная тема с неоновыми эффектами |
| 📱 **Адаптивность** | Работает на всех устройствах |
| ✨ **Анимации** | Плавные появления, эффект слежения за мышью |
| 🖼️ **Слайдер портфолио** | С прокруткой, свайпами и прогресс-баром |
| 📝 **Форма связи** | Отправка сообщений на почту через PHPMailer |
| 🧩 **Модульный SASS** | Стили разбиты по компонентам |
| 🍔 **Бургер-меню** | Для мобильных устройств |
| 🎯 **Снаппинг** | Плавная прокрутка по секциям |

---

## 🛠️ Технологии

| Технология | Использование |
|------------|---------------|
| HTML5 | Структура страницы |
| SASS (SCSS) | Стилизация (модульная архитектура) |
| JavaScript | Анимации, слайдер, маска телефона, AJAX |
| PHPMailer | Отправка писем через SMTP |
| IMask | Маска для ввода телефона |
| Intersection Observer | Анимации при скролле |


---

## 🚀 Запуск

1. Склонируй репозиторий
2. Открой `index.html` через Live Server
3. Для работы формы нужен сервер с PHP
